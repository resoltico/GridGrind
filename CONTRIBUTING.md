# Contributing

Use [Development](docs/DEVELOPER.md) for setup and verification, and
[Architecture](docs/ARCHITECTURE.md) for ownership. Read the affected behavior tests before changing behavior.
Preserve unrelated work and private state. Use synthetic examples in public issues and pull requests.

Before submitting, read the [contribution terms](PROJECT-NOTICE.md#contribution-terms).
Confirm your agreement using the checkbox in the pull request template.

The owner reviews and merges changes. Passing checks record execution evidence and do not authorize
merging, tagging, publishing or changing repository protections. Follow [AGENTS.md](AGENTS.md) when using
a coding agent.
